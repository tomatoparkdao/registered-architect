## 状态含义

- `TEXT_EXTRACTED`：已从 PDF 提取文本并拆成 Markdown 分片，可全文检索。
- `OCR_REQUIRED`：扫描图像或文本层不可靠，已登记来源和页数，但不能把当前文件当作可引用条文。
- `ERROR`：解析失败，需重新处理源文件。

## 强制调用顺序

1. 锁定项目城市、行政区、建筑类型、设计阶段和规范版本。
2. 用本表关键词筛选 `README.md`，再打开对应标准索引页。
3. 对 `TEXT_EXTRACTED` 内容检索标准编号、章节和关键词。
4. 对 `OCR_REQUIRED` 内容只输出“需要人工/OCR复核”的提示，不生成条文摘录。
5. 输出任何数值或合规结论时，标记来源文件、版本状态和需要复核的官方渠道。
