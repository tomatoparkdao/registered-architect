# 建筑类型学技能

你是建筑类型学专家，掌握各主要用途类别的平面类型、结构体系、尺寸标准和代表性建筑。你理解类型选择如何影响密度、效率、采光、建造成本、使用体验和城市形态。所有建议都基于可量化指标和真实项目先例。

## 1. Residential Typologies

### 1.1 独立住宅

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 8–12 m（设中央走道或采光井时可更深） |
| 层数 | 通常 1–3 层 |
| 地块宽度 | 8–20 m |
| 典型 GIA | 80–300 m² |
| 密度 | 10–30 DU/ha |
| NTG 比率 | 0.85–0.92（公共面积最少） |
| 结构体系 | 承重砌体、木框架、轻钢框架 |
| 停车 | 地块内车库或车道，1–3 个车位 |
| 采光 | 所有房间可在 2 个或更多侧面开窗；采光优秀 |
| 私享配套 | 前后花园，50–200+ m² |

**Exemplars:**
- Farnsworth House (Mies van der Rohe, 1951, Plano IL) -- universal open plan, glass pavilion, 140 m2
- Maison Bordeaux (OMA/Rem Koolhaas, 1998) -- split-level, hydraulic platform, 500 m2
- Moriyama House (SANAA/Ryue Nishizawa, 2005, Tokyo) -- cluster of discrete volumes, 263 m2 total

### 1.2 联排半独立住宅

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 8–10 m |
| 层数 | 2–3 层 |
| 地块宽度 | 每户 5–8 m（两户合计 10–16 m） |
| 每户典型 GIA | 70–150 m² |
| 密度 | 25–50 DU/ha |
| 分户墙 | 最小 100 mm 空腔砌体，STC 45+ |
| 停车 | 地块内车道，每户 1–2 个车位 |
| 采光 | 三面采光（前、后、侧）；分户墙无窗 |

**Exemplars:**
- Donnybrook Quarter (Peter Barber Architects, 2006, London) -- contemporary semi-detached with courtyard variants, 65 DU/ha
- Accordia (Feilden Clegg Bradley / Maccreanor Lavington / Alison Brooks, 2008, Cambridge) -- mixed semi-detached and terrace, 47 DU/ha

### 1.3 联排住宅

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 8–12 m |
| 平面宽度 | 每户 4.5–7 m |
| 层数 | 2–4 层 |
| 每户典型 GIA | 65–140 m² |
| 密度 | 40–80 DU/ha |
| NTG 比率 | 0.85–0.90 |
| 结构体系 | 承重分户墙（砌体/混凝土砌块）、木楼板 |
| 停车 | 路边、后侧服务巷庭院或内置车库（会减少可居住面积） |
| 采光 | 仅两面采光（前、后）；为保证后部房间采光，最大进深 12 m |
| 私享配套 | 后花园 20–60 m²，前院 3–10 m² |

**关键尺寸：**
- 两居室最小宽度：4.5 m（室内）；建议 5.0–5.5 m
- 三居室最小宽度：5.5 m；建议 6.0–7.0 m
- 楼梯宽度：净宽最小 850 mm，建议 900 mm
- 走廊：净宽最小 900 mm

**Exemplars:**
- Georgian Terrace (Bath, London, Edinburgh, 1714-1830) -- 5-7m wide, 12-15m deep, 3-4 storeys, the prototype
- Borneo Sporenburg (various architects, 2000, Amsterdam) -- 5.1m wide, 3 storeys, courtyard within plan depth, 100 DU/ha
- Goldsmith Street (Mikhail Riches, 2019, Norwich) -- Stirling Prize, Passivhaus terrace, 5.2m wide, south-facing orientation

### 1.4 步行楼梯公寓（3–5 层）

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 10–14 m（单侧走道：6–8 m） |
| 核心类型 | 每层由一部楼梯服务 4–8 户（许多规范中 5 层以下可不设电梯） |
| 每核心户数 | 楼梯入户型每个平台 2–4 户；走道型每层 6–12 户 |
| 典型户型面积 | 45–90 m² NIA |
| 密度 | 60–150 DU/ha |
| NTG 比率 | 0.78–0.84 |
| 结构体系 | 承重砌体、交叉层压木（CLT）、钢筋混凝土框架 |
| 停车 | 地面、架空层或地下室；每户 0.5–1.0 个车位 |
| 采光 | 楼梯入户型可实现双面采光；走道型常为单面采光 |

**核心配置：**
- **楼梯入户（无走道）：**一部楼梯，每个平台 2–4 户。效率最高，最有利于双面采光。常见于欧洲大陆（柏林、巴黎、维也纳）。
- **单侧走道：**走道位于一侧，住宅单元位于另一侧，所有单元朝向相同。采光良好但效率较低（NTG 0.72–0.78）。
- **双侧走道：**走道位于中部，两侧布置住宅单元。面积效率最高，但两侧单元均为单面采光。平面进深 12–15 m。

**Exemplars:**
- Silodam (MVRDV, 2003, Amsterdam) -- mixed walk-up and maisonette, 157 units, harbour location
- Ely Court (Alison Brooks Architects, 2015, London) -- brick walk-up, stair-access cores, dual-aspect
- 85 Falkner Street (shedkm, 2018, Liverpool) -- CLT walk-up apartments, Passivhaus

### 1.5 中层公寓（6–12 层）

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 12–18 m（双侧走道） |
| 楼板面积 | 600–1,500 m² GIA |
| 核心类型 | 1–2 部电梯 + 1 部消防楼梯 + 1 部疏散楼梯（取决于规范） |
| 每核心每层户数 | 4–10 户 |
| 典型户型配比 | 一居 30–40%，两居 35–45%，三居 15–25% |
| 密度 | 100–250 DU/ha |
| NTG 比率 | 0.75–0.82 |
| 结构体系 | 钢筋混凝土框架、无梁楼板（最常见）、钢筋混凝土剪力墙+无梁楼板、CLT（最高约 10 层） |
| 结构网格 | 住宅典型 6.0 m × 7.5 m |
| 层高 | 2.85–3.15 m |
| 停车 | 地下室或裙房；每户 0.3–1.0 个车位 |
| 采光 | 双面采光（转角、端部）与单面采光（中部）混合；平面进深至关重要 |

**关键设计原则：**
- 走道距核心筒长度不应超过 30 m（消防疏散）
- 每层至少 2 户双面采光单元（转角户）
- 应避免朝北的单面采光单元（采光和太阳得热较差）
- 每个住宅入口 30 m 内设置垃圾滑道
- 无障碍住宅单元分布在各楼层（Part M Category 2 为最低要求，Category 3 占 10%）

**Exemplars:**
- Via Verde (Grimshaw + Dattner, 2012, Bronx NY) -- 222 units, stepped profile, rooftop agriculture, mixed affordable
- One Folgate Street (Alison Brooks Architects, 2018, London) -- 8 storeys, brick, dual-aspect, mixed tenure
- The Interlace (OMA/Ole Scheeren, 2013, Singapore) -- 31 blocks of 6 storeys, stacked at angles, 1,040 units, 170,000 m2

### 1.6 高层住宅塔楼（13 层以上）

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 点式塔楼：直径 18–24 m；板式塔楼：进深 12–16 m |
| 楼板面积 | 点式塔楼 400–900 m² GIA；板式塔楼 800–2,000 m² |
| 核心筒面积 | 80–150 m²（电梯+楼梯+前室+管井） |
| 核心筒/GIA 比率 | 点式塔楼 20–28%；板式塔楼 15–22% |
| 电梯 | 每 80–120 户至少 2 部，另设 1 部消防电梯 |
| 每核心每层户数 | 点式塔楼 4–8 户；板式塔楼 8–16 户 |
| 密度 | 200–600+ DU/ha |
| NTG 比率 | 点式塔楼 0.68–0.78；板式塔楼 0.72–0.82 |
| 结构体系 | 钢筋混凝土核心筒+无梁楼板、钢筋混凝土核心筒+后张楼板、钢筋混凝土核心筒+外围钢结构 |
| 层高 | 标准 3.0–3.3 m；豪宅 3.5–4.0 m |
| 风环境 | 10 层以上需进行风分析；15 层以上转角阳台存在风环境问题 |
| 停车 | 地下裙房（2–5 层）；每户 0.2–1.0 个车位 |

**塔楼核心筒设计：**
- **剪刀楼梯：**两部交错楼梯设置在同一井道内，紧凑且满足双楼梯疏散要求。英国常见，最高可用于约 30 层。
- **双楼梯：**核心筒两侧设置两部独立楼梯。IBC 及许多国际规范对高层建筑要求采用该形式。
- **单楼梯（有条件）：**部分英国规范在低于特定高度/使用人数阈值时允许采用。每户直接开向楼梯前室。
- **隔层停靠：**每 3 层设置一条走道，中间布置复式住宅。可减少走道面积并提高 NTG（Unité d'Habitation 模式）。

**Exemplars:**
- Unité d'Habitation (Le Corbusier, 1952, Marseille) -- 18 storeys, skip-stop corridor, 337 units, internal street concept
- Barbican Estate (Chamberlin Powell & Bon, 1969-76, London) -- three 42-storey towers, 2,014 units, brutalist
- 432 Park Avenue (Rafael Vinoly, 2015, New York) -- 85 storeys, 28.5m x 28.5m plan, 104 units, one of tallest residential
- One Thousand Museum (Zaha Hadid Architects, 2019, Miami) -- 62 storeys, exoskeleton structure, 83 units
- Bosco Verticale (Stefano Boeri, 2014, Milan) -- 2 towers (111m, 76m), 900 trees, 20,000 plants, 113 units

### 1.7 复式公寓

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 8–14 m |
| 每户层数 | 2 层（公寓楼内复式） |
| 典型 GIA | 65–120 m² |
| 交通 | 每隔一层设置走道（隔层停靠），或设置私人外部楼梯 |
| 优点 | 起居空间双面采光，内部楼梯带来住宅感，减少走道面积 |
| 缺点 | 每户内部楼梯占用 3–4 m² NIA，无障碍挑战（仅入口层可达） |

**Exemplars:**
- Alexandra Road Estate (Neave Brown / Camden Architects, 1978, London) -- stepped maisonettes, 520 dwellings
- Brunswick Centre (Patrick Hodgkinson, 1972, London) -- stepped maisonettes facing central street

### 1.8 庭院住宅

| 指标 | 数值 |
|--------|-------|
| 平面进深 | 围绕 6–15 m 庭院的翼楼进深 6–10 m |
| 层数 | 1–3 层 |
| 典型 GIA | 60–200 m² |
| 密度 | 40–100 DU/ha |
| 庭院尺寸 | 采光最小 4 m × 4 m；可用室外空间建议 6 m × 6 m |
| 优点 | 私密性、微气候、为深进深空间提供采光、文化传统延续 |
| 结构体系 | 承重墙（砌体、夯土、混凝土） |

**Exemplars:**
- Salk Institute (Louis Kahn, 1965, La Jolla CA) -- courtyard as monumental space between lab wings
- Courtyard Houses Matosinhos (Souto de Moura, 1993-99, Portugal) -- minimalist courtyard villa
- Bait Ur Rouf Mosque (Marina Tabassum, 2012, Dhaka) -- courtyard as environmental mediator

### 1.9 共享居住

| 指标 | 数值 |
|--------|-------|
| 社区规模 | 15–40 户（有利于社会凝聚） |
| 私人单元 | 40–100 m² NIA（小于传统住宅，由共享空间补偿） |
| 共享空间 | 公共住宅：150–300 m²（厨房、餐厅、休息室、洗衣房、客房、工作坊） |
| 共享/私人比率 | 总 NIA 的 10–20% 为共享空间 |
| 布局 | 围绕共享庭院或花园成组；停车位布置在外围 |
| 密度 | 30–80 DU/ha |

**Exemplars:**
- Trudeslund (1981, Birkerod, Denmark) -- one of the earliest, 33 households, one-storey
- Marmalade Lane (Mole Architects, 2019, Cambridge) -- 42 homes, common house, car-free street
- Lilac (2013, Leeds) -- mutual home ownership, straw bale construction, 20 households

### 1.10 Micro / Co-Living

| Metric | Value |
|--------|-------|
| Private Unit | 10 - 25 m2 NIA (bedroom + en-suite or pod bathroom) |
| Shared Spaces | Kitchen, living, laundry, co-working, gym: 5-10 m2/unit |
| Building Type | Typically mid-rise apartment, repurposed hotel, or purpose-built |
| Density | 200 - 500+ DU/ha |
| NTG Ratio | 0.65 - 0.75 (extensive shared space) |
| Target User | Young professionals, students, digital nomads, short-term workers |

**Exemplars:**
- The Collective Old Oak (PLP Architecture, 2016, London) -- 546 units, largest co-living building in the world at completion
- Carmel Place (nARCHITECTS, 2016, New York) -- 55 micro-units, 23-33 m2, modular prefab construction
- StarCity (various locations, 2020+) -- co-living operator, units from 14 m2 with extensive shared amenity

## 2. 办公类型学

### 2.1 标准化外壳与核心筒

| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 典型 1,000–2,500 m² NIA；伦敦金融城优质办公楼 1,500–2,000 m² |
| 平面进深（核心筒至玻璃） | 12–15 m（BCO 建议自然通风区最大 15 m） |
| 层高 | 3.6–4.2 m（BCO 标准典型 3.9 m） |
| 吊顶高度 | 装修完成后 2.6–2.85 m（BCO 最小 2.6 m，建议 2.7–2.8 m） |
| 架空地板高度 | 100–150 mm（BCO 为实现完全灵活性建议最小 150 mm） |
| 吊顶内空间 | 400–600 mm（设备分配和声学吊顶） |
| 结构高度 | 300–500 mm（后张楼板 300 mm；组合结构 400–500 mm） |
| 结构网格 | 7.5 m、9.0 m、10.8 m 或 12.0 m（须与下方停车网格 7.2 m 或 7.5 m 协调） |
| NTG 比率 | 0.80–0.85（BCO 目标 82.5%） |
| 核心筒/GIA | 15–22% |
| 楼面荷载 | 2.5 kN/m² + 1.0 kN/m² 隔墙荷载（最小值） |

**Exemplars:**
- Willis Building (Foster + Partners, 2007, London) -- crescent plan, 46,450 m2, column-free 18m spans
- The Leadenhall Building (Rogers Stirk Harbour, 2014, London) -- 51 storeys, external bracing, tapered form, 84,424 m2
- 22 Bishopsgate (PLP Architecture, 2020, London) -- 62 storeys, 128,000 m2, largest office floor plates in City of London

### 2.2 自用办公 / 企业总部

| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 2,000–10,000+ m²（单一使用者，平面通常更深） |
| 平面进深 | 15–25 m（通过内部中庭将日光引入深进深空间） |
| 层高 | 3.9–4.5 m（为业主指定设备提供更宽裕空间） |
| NTG 比率 | 0.72–0.80（公共区、中庭和配套更充裕） |
| 典型特征 | 中庭、品牌化接待厅、员工餐厅、健身中心、全员大会空间 |

**Exemplars:**
- Inland Steel Building (SOM/Bruce Graham, 1958, Chicago) -- first modern curtain wall office tower, all services in separate tower, 18.3m clear spans, 19 storeys
- Apple Park (Foster + Partners, 2017, Cupertino) -- 260,000 m2 ring plan, 1.6km circumference, 12,000 employees
- Bloomberg European HQ (Foster + Partners, 2017, London) -- 102,000 m2, BREEAM Outstanding (98.5%), spiralling ramp circulation

### 2.3 共享办公 / 灵活空间

| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 每个地点 1,000–5,000 m² |
| 工位密度 | 6–8 m²/人（比传统办公更密集） |
| 共享比率 | 每位会员 0.6–0.8 个工位 |
| 会议室比率 | 每 15–20 位会员 1 间 |
| 配套面积 | NIA 的 20–30%（厨房、休息室、活动空间、电话亭） |
| NTG 比率 | 0.72–0.78（配套和交通面积较多） |
| 层高 | 偏好 >3.5 m 的高层高（设备外露美学） |

**Exemplars:**
- WeWork (various locations) -- standardised fit-out, 60-80% open desk, glass-fronted offices
- Second Home (Selgascano, 2014, London) -- elliptical glass offices within open-plan, 2,500 m2
- Factory Berlin (Julian Breinersdorfer, 2014) -- adaptive reuse, 14,000 m2, start-up campus

### 2.4 办公园区

| 指标 | 数值 |
|--------|-------|
| 场地面积 | 5–50+ ha |
| 建筑覆盖率 | 20–40%（景观空间充裕） |
| 楼板面积 | 每栋 2,000–5,000 m² |
| 层数 | 通常 2–6 层（低层园区特征） |
| 密度 | 0.3–0.8 FAR |
| 停车 | 地面或集中式停车；每 30–50 m² NIA 配 1 个车位 |
| 配套 | 中央枢纽（餐饮、健身、零售）、室外运动/休闲 |

**Exemplars:**
- Googleplex (various architects, Mountain View) -- campus of low-rise buildings, 100,000+ employees across Silicon Valley
- Novo Nordisk HQ (Henning Larsen, 2014, Copenhagen) -- 3 concentric rings, 73,000 m2, LEED Platinum
- Samsung Semiconductor (NBBJ, 2015, San Jose) -- 102,000 m2, 10-storey intersecting volumes

## 3. 医疗建筑类型学

### 3.1 医院平面类型

**裙房 + 塔楼：**
| 指标 | 数值 |
|--------|-------|
| 裙房 | 2–4 层，为临床科室提供大楼板（5,000–15,000 m²） |
| 塔楼 | 裙房上方 6–15 层，用于住院病房（楼板 1,000–2,000 m²） |
| 优点 | 临床科室拥有大跨度无柱楼板；病房获得日光和景观 |
| 缺点 | 竖向交通距离长；裙房与塔楼交界处转换结构复杂 |
| 代表项目 | Royal London Hospital（HOK/Skanska，2012）——17 层、115,000 m²，英国最大的 新建医院 |

**庭院 / 棋盘式：**
| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 3,000–8,000 m²，内部庭院提供采光 |
| 层数 | 3–6 层 |
| 优点 | 所有科室位于低层，水平交通短，深进深空间可获得自然光 |
| 缺点 | 基底面积大，需要较大场地；竖向扩建能力有限 |
| 代表项目 | Khoo Teck Puat Hospital（CPG Consultants，2010，新加坡）——庭院平面、亲生物设计、590 张床位 |

**指状平面（亭式）：**
| 指标 | 数值 |
|--------|-------|
| 平面 | 线性翼楼（手指）由中央脊柱走道连接 |
| 翼楼进深 | 每个翼楼 12–18 m |
| 间距 | 翼楼之间 18–25 m（用于采光和通风） |
| 优点 | 采光通风优秀，可通过增加翼楼分期扩建 |
| 缺点 | 水平交通距离长，需要较大场地 |
| 代表项目 | Nightingale 模式医院（19 世纪）；现代项目：Alder Hey Children's Hospital（BDP，2015，利物浦） |

**核心 / 紧凑式：**
| 指标 | 数值 |
|--------|-------|
| 平面 | 围绕中央核心筒的紧凑十字形或放射形平面 |
| 楼板面积 | 2,000–4,000 m² |
| 优点 | 交通距离短，设备服务效率高 |
| 缺点 | 中央区域采光有限，寻路复杂 |
| 代表项目 | NHS Nucleus 模板医院（英国 1970–80 年代） |

### 3.2 医疗建筑关键指标

| 指标 | 标准 |
|--------|----------|
| 走道宽度（病床通行） | 净宽最小 2.4 m；建议 2.7 m |
| 走道宽度（员工/患者步行） | 最小 1.8 m；建议 2.1 m |
| 病房门宽度 | 净宽最小 1.2 m（病床通行） |
| 护士站可视性 | 可直接看到单元内所有床位（每单元最多 28–32 床） |
| 清洁—污染流线 | 单向；无菌 > 清洁 > 污染，不得回流 |
| 科室叠置 | 急诊和影像位于首层；手术部位于急诊上方；病房位于手术部上方 |
| 层高 | 4.2–5.0 m（医院典型值，部分设计设设备夹层） |
| NTG 比率 | 0.55–0.65（因宽走道和复杂设备系统，是效率最低的建筑类型之一） |

### 3.3 诊所 / 手术中心

| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 500–3,000 m² |
| 层数 | 1–3 层 |
| 核心空间 | 候诊、接待、诊室、治疗室、员工区 |
| 诊室 | 14–16 m²（全科医生诊室最小 12 m²） |
| 候诊区 | 每位同时候诊患者 1.5–2.0 m² |
| NTG 比率 | 0.70–0.78 |
| 停车 | 每间诊室 3–5 个车位 |

**Exemplar:** Maggie's Centres (various architects: Gehry, Hadid, Heatherwick, Chipperfield) -- 200-400 m2, domestic scale, open-plan kitchen as heart, no waiting room, garden

## 4. 教育建筑类型学

### 4.1 小学

| 指标 | 数值 |
|--------|-------|
| 场地面积 | 1.0–2.0 ha（1 FE = 210 名学生） |
| GIA | 1,100–2,200 m²（按 BB103，1FE–3FE） |
| 层数 | 1–2 层（低龄儿童优先采用单层） |
| 教室 | 55–63 m²，至少 2.0 m²/学生 |
| 走道宽度 | 最小 1.8 m；建议 2.4 m（兼作社交/展示空间） |
| 集会/餐厅 | 120–170 m²（小型学校可兼作体育空间） |
| NTG 比率 | 0.72–0.78 |
| 采光 | 每个教学空间必须有窗；平均日光因子至少 2% |

**平面类型：**
- **指状平面：**教室布置在平行翼楼中，翼楼之间设置室外空间。采光和自然通风良好，但需要较大场地。
- **集群：**教室围绕共享学习空间成组布置，支持协作教学，常见于现代英国学校。
- **街道式：**中央设置宽阔、采光良好的走道，两侧布置教室。紧凑且高效。
- **庭院式：**教室围合安全的室外空间，适合城市场地并利于被动监护。

**Exemplars:**
- Burntwood School (Allford Hall Monaghan Morris, 2015, London) -- RIBA Stirling Prize, prefabricated CLT classrooms
- Fuji Kindergarten (Tezuka Architects, 2007, Tokyo) -- oval roof as playground, open-air classrooms, 600 children
- Westborough Primary School (Cottrell & Vermeulen, 2001, Southend) -- straw bale construction, environmental showcase

### 4.2 中学

| 指标 | 数值 |
|--------|-------|
| 场地面积 | 3.0–7.0 ha（6FE–12FE = 900–1,800 名学生） |
| GIA | 6,000–12,000 m²（按 BB103） |
| 层数 | 2–4 层 |
| 教室 | 55–65 m²（30 名学生） |
| 专业教室 | 80–110 m²（科学实验室、工作坊、工作室） |
| 体育馆 | 594 m²（4 场地）；891 m²（6 场地） |
| 走道宽度 | 2.4–3.0 m（高交通量、储物柜和展示需求） |
| NTG 比率 | 0.68–0.75 |
| 层高 | 3.3–3.9 m（体育馆和专业空间需要更高） |

**Exemplars:**
- School of Engineering and Science, Aalborg University (C.F. Moller, 2010) -- open labs, flexible teaching
- Orestad Gymnasium (3XN, 2007, Copenhagen) -- open-plan school, flexible learning, 4 storeys around central stair
- Whitby Academy (GSSArchitecture, 2013) -- compact 3-storey, central atrium, 900 pupils

| NTG 比率 | 0.60–0.72（实验室占比高的建筑较低） |

**Exemplars:**
- Rolex Learning Centre (SANAA, 2010, Lausanne) -- single undulating floor plate, 20,000 m2, no internal walls
- Li Ka Shing Knowledge Institute (Diamond Schmitt, 2011, Toronto) -- medical school, simulation labs, 16 storeys
- Saw Swee Hock Student Centre (O'Donnell + Tuomey, 2014, LSE, London) -- RIBA award, angular form, 6,300 m2

## 5. 文化建筑类型学

### 5.1 博物馆

**平面类型：**

**线性序列（Enfilade）：**
房间按序连接，参观者沿规定路线行进，可完全控制叙事。示例：Vatican Museums、Uffizi。

**自由流线（开放平面）：**
大型开放展厅采用可移动隔断，参观者自行选择路径，适合变化展览。示例：Centre Pompidou（Piano + Rogers，1977，巴黎）、Tate Modern Turbine Hall。

**混合式（序列 + 自由流线）：**
常设展按序列布置，临时展览采用自由流线空间，是当代最常见的方法。

| 指标 | 数值 |
|--------|-------|
| 展厅层高 | 绘画 4.5–6.0 m；大型雕塑/装置 6.0–10.0 m |
| 展厅宽度 | 墙面绘画 6–12 m；雕塑、装置 15–30 m |
| 展厅比例 | 绘画展厅宽:长为 1:1.5 至 1:2 |
| 悬挂高度 | 视线高度 1.5 m；作品中心 1.45–1.55 m |
| 照明（绘画） | 最大 200 lux；过滤紫外线；无直射阳光 |
| 照明（纸质作品） | 最大 50 lux；无自然光 |
| 环境控制 | 20 ± 2°C，50 ± 5% RH，全年 24/7/365 |
| BOH 比率 | 公共面积的 40–60%（保护、储藏、装卸、办公） |
| NTG 比率 | 0.55–0.65 |
| 楼面荷载 | 雕塑展厅最小 5.0 kN/m² |

**Exemplars:**
- Guggenheim Bilbao (Frank Gehry, 1997) -- 24,000 m2, titanium-clad, free-flow + sequential galleries, the "Bilbao Effect"
- MAXXI (Zaha Hadid, 2010, Rome) -- flowing concrete galleries, 21,000 m2, no right angles
- Louvre Abu Dhabi (Jean Nouvel, 2017) -- 9,200 m2 galleries under 180m diameter dome, "rain of light"
- Tate Modern (Herzog & de Meuron, 2000 + 2016, London) -- Bankside Power Station conversion, 35,000 m2

### 5.2 剧场与礼堂

**配置类型：**

| 类型 | 描述 | 容量范围 | 演员—观众距离 |
|------|------------|---------------|------------------------|
| 镜框式 | 舞台位于镜框后方，观众位于前方 | 300–2,500 | 15–30 m |
| 伸出式 | 舞台三面伸入观众区 | 200–1,200 | 8–18 m |
| 环形（四面舞台） | 观众环绕舞台 | 100–600 | 5–12 m |
| 黑盒子 | 灵活可重构空间 | 50–400 | 可变 |
| 庭院式 | 观众席分布在多层廊座并围绕舞台 | 200–1,000 | 8–20 m |

| 指标 | 标准 |
|--------|----------|
| 座椅宽度 | 500–530 mm（最小），550 mm（高档） |
| 排距 | 前后排 760–850 mm（视线最小 760 mm） |
| 走道宽度 | 最小 1.1 m（IBC），高容量场馆需更宽 |
| 视线（C 值） | 电影院 65–125 mm；剧场 100–130 mm；每个座位均应越过前方观众头部看到舞台 |
| 声学体积 | 交响乐 6–10 m³/座；戏剧 4–7 m³/座；电影院 3–5 m³/座 |
| 混响时间（RT60） | 交响乐 1.7–2.2 s；戏剧 1.0–1.4 s；语言/电影院 0.6–0.8 s |
| 舞台进深 | 镜框式 10–14 m |
| 舞台塔高度 | 镜框开口高度的 2.5 倍（通常高出舞台 22–30 m） |
| BOH/FOH 比率 | 小型场馆 0.7–1.0；大型歌剧院 1.0–1.5 |
| NTG 比率 | 0.45–0.55（表演艺术建筑效率最低） |

**Exemplars:**
- Sydney Opera House (Jorn Utzon, 1973) -- multiple venues, 5,738 seats total, expressionist shells
- Elbphilharmonie (Herzog & de Meuron, 2017, Hamburg) -- 2,100-seat vineyard hall on converted warehouse, 110m tall
- National Theatre (Denys Lasdun, 1976, London) -- three auditoria (Olivier, Lyttelton, Dorfman), brutalist terraces
- Harbin Opera House (MAD Architects, 2015) -- 1,600 seats, organic form, Manchurian landscape

### 5.3 图书馆

| 指标 | 数值 |
|--------|-------|
| 书库面积 | 每 1,000 册 5–7 m²（开放书架）；移动书架可减半 |
| 阅览空间 | 每位读者 4–5 m² |
| 数字/计算机空间 | 每个工作站 3–4 m² |
| 儿童区 | 30–80 m²（独立设置，优先位于首层） |
| 楼面荷载 | 书库最小 6.5 kN/m²；阅览区 2.5 kN/m² |
| 层高 | 阅览室 3.0–4.0 m；书库最小 2.7 m |
| NTG 比率 | 0.65–0.75 |
| 采光 | 阅览区优先采用自然光，但应避免藏书受到直射阳光 |

**Exemplars:**
- Seattle Central Library (OMA/Rem Koolhaas, 2004) -- 34,000 m2, "Book Spiral" continuous stack ramp, faceted glass skin
- Library of Birmingham (Mecanoo, 2013) -- 31,000 m2, interlocking gold circles facade, 10 storeys
- Tianjin Binhai Library (MVRDV, 2017) -- the "Eye," 33,700 m2, undulating bookshelves, central sphere auditorium

## 6. 酒店与接待建筑类型学

### 6.1 酒店平面类型

**双侧走道式：**
| 指标 | 数值 |
|--------|-------|
| 走道宽度 | 经济型 1.5–1.8 m；豪华型 1.8–2.1 m |
| 房间进深 | 经济/中档 6.0–8.0 m；豪华 8.0–12.0 m |
| 房间宽度 | 经济型 3.3–3.6 m；中档 3.6–4.5 m；豪华 4.5–6.0 m |
| 每层房间数 | 每个走道翼楼 20–40 间 |
| NTG 比率 | 0.62–0.72 |
| 优点 | 布局效率最高；每层房间数量最大 |
| 缺点 | 房间单面采光；走道长且具有机构化特征 |

**中庭式：**
| 指标 | 数值 |
|--------|-------|
| 中庭宽度 | 15–30 m |
| 中庭高度 | 建筑全高（戏剧性强） |
| 每层房间数 | 每层 30–80 间（围绕中庭） |
| NTG 比率 | 0.55–0.65（中庭占用 GIA） |
| 优点 | 形成戏剧性到达体验，为走道提供采光，便于寻路 |
| 缺点 | 声学问题、消防工程复杂、效率较低 |
| 代表项目 | Hyatt Regency Atlanta（John Portman，1967）——首座中庭酒店，22 层、800 间客房 |

**庭院式：**
| 指标 | 数值 |
|--------|-------|
| 庭院尺度 | 横向 15–40 m |
| 层数 | 2–5 层 |
| NTG 比率 | 0.58–0.68 |
| 优点 | 提供室外配套、采光和度假村特征 |
| 代表项目 | Aman Venice（Papadopoli Palace 改造）——历史庭院酒店 |

**塔楼式：**
| 指标 | 数值 |
|--------|-------|
| 楼板面积 | 800–2,000 m² GIA |
| 每层房间数 | 12–30 间 |
| 核心筒 | 2 部以上电梯、服务电梯、消防电梯、2 部楼梯 |
| NTG 比率 | 0.60–0.68 |
| 代表项目 | Marina Bay Sands（Moshe Safdie，2010，新加坡）——3 座塔楼、2,561 间客房、SkyPark |

| 指标 | 经济型 | 中档 | 高档 | 豪华 |

## 7. 混合与综合用途建筑类型学

### 7.1 裙房—塔楼

| 指标 | 数值 |
|--------|-------|
| 裙房 | 2–6 层，大楼板（2,000–10,000 m²），零售/办公/停车 |
| 塔楼 | 10–80+ 层，小楼板（400–2,000 m²），住宅/酒店/办公 |
| 转换结构 | 位于裙房—塔楼交界处；转换梁/板深度可达 3 m |
| 退台 | 塔楼从裙房边缘后退（通常 3–5 m），形成配套露台 |
| 优点 | 裙房高度形成城市街墙；塔楼提高密度；支持混合用途 |
| 缺点 | 转换结构成本高；设备服务复杂；不同用途之间需要防火分隔 |

**Exemplars:**
- De Rotterdam (OMA, 2013, Rotterdam) -- three interconnected towers on shared podium, 162,000 m2, office/residential/hotel
- Brickell City Centre (Arquitectonica, 2016, Miami) -- mixed-use, climate ribbon, retail podium + residential towers
- Battersea Power Station Phase 2 (Foster + Partners / Gehry Partners, 2021, London) -- retained power station as podium, new residential towers

### 7.2 叠置用途（竖向混合用途）

| 指标 | 数值 |
|--------|-------|
| 典型叠置顺序（由下至上） | 停车 > 零售 > 办公 > 酒店 > 住宅 |
| 逻辑 | 较重用途位于下部，公共用途位于地面层，安静用途位于上部 |
| 防火分隔 | 不同用途类别之间设置 2 小时耐火楼板（IBC/EN） |
| 声学分隔 | 住宅与商业之间空气声最小 50 dB + 撞击声最小 55 dB |
| 独立核心筒 | 每种用途均需独立电梯厅和消防疏散系统 |
| 共享设备服务 | 设置中央设备机房，计量后分配至各用途 |
| 层高差异 | 零售 4.5 m，办公 3.9 m，酒店 3.3 m，住宅 3.0 m |

### 7.3 并置式

| 指标 | 数值 |
|--------|-------|
| 配置 | 不同用途布置在相邻体量中，共享基座/地面层 |
| 优点 | 结构体系独立，消防工程更简单 |
| 缺点 | 需要较宽场地；密度低于竖向叠置 |
| 分隔 | 用途之间设置防火墙；共享裙房层用于零售/公共功能 |

### 7.4 竖向村落

| 指标 | 数值 |
|--------|-------|
| 概念 | 在单座高层建筑内形成自给自足的社区，将所有用途竖向整合 |
| 空中大堂 | 每 10–15 层设置一处，配置共享配套（花园、零售、社交空间） |
| 结构 | 在空中大堂设置伸臂桁架抵抗风荷载 |
| 代表项目 | The Interlace（OMA，2013，新加坡）——水平村落概念；新加坡 WOHA Architects 项目（如 Oasia Hotel Downtown，2016——314 间客房，每 6 层设置空中花园，绿地率 89%） |

### 7.5 混合用途设计关键挑战

| 挑战 | 解决策略 |
|-----------|-----------|
| 入口分隔 | 每种用途设置独立大堂和地址；住宅入口必须与商业入口区分 |
| 设备服务冲突 | 设置独立装卸区或按时间管理的共享装卸区；垃圾收集分开 |
| 结构网格不匹配 | 办公（9 m 网格）与住宅（6–7.5 m 网格）及停车（7.2 m 网格）不一致——采用转换结构 |
| 层高变化 | 不同层高要求在界面处进行精细剖面设计 |
| 声学隔离 | 采用浮筑楼板、隔离结构连接和用途转换处的缓冲楼层 |
| 消防疏散 | 每种用途均须独立疏散至地面；不得共用疏散路线 |
| 风环境影响 | 塔楼位于裙房上方会形成下洗气流；需进行行人舒适度风环境研究 |
| 停车分配 | 各用途设置独立停车区；错峰使用可减少共享车位总量 |
