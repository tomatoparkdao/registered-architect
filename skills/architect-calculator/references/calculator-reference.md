# 计算器参考 —— 公式与方法

七个建筑设计计算器所采用的详细公式、常数和方法。

---

## 1. 面积计算器

### 公式

```
GFA = Site Area x FAR
NGA = GFA x NTG Ratio
Units = floor(NGA / Avg Unit Size)
Population = Units x Persons per Unit
Parking = Units x Parking Ratio
```

### 关键比率

| 建筑类型            | 典型 NTG 比率     |
|--------------------|-------------------|
| 住宅（公寓）        | 0.75 - 0.85      |
| 办公                | 0.80 - 0.88      |
| 零售                | 0.85 - 0.92      |
| 医院                | 0.55 - 0.65      |
| 酒店                | 0.65 - 0.75      |
| 学校                | 0.70 - 0.80      |

NTG 比率计入交通空间（走道、大堂、楼梯、电梯）、结构构件（柱、墙）和设备用房
（机房、电气间、储藏室）。

### 开发强度基准

| 开发强度指标            | 低密度     | 中密度     | 高密度       |
|------------------------|-------------|------------|-------------|
| FAR                    | 0.5 - 1.0  | 1.5 - 3.0 | 4.0 - 15.0 |
| 住宅单元/公顷          | 30 - 50    | 75 - 150   | 200 - 500+  |
| 人口/公顷              | 75 - 125   | 200 - 400  | 500 - 1500+ |

## 2. 传热系数（U 值）计算器

### 公式

```
R_total = Rsi + sum(thickness_i / conductivity_i) + Rse
U = 1 / R_total
```

其中：
- Rsi = 内表面热阻（m2K/W）
- Rse = 外表面热阻（m2K/W）
- thickness 的单位为米（输入单位为 mm，程序会转换）
- conductivity 的单位为 W/mK

### 表面热阻取值（ISO 6946）

| 位置             | 热流方向               | Rsi (m2K/W) | Rse (m2K/W) |
|-----------------|----------------------|-------------|-------------|
| 外墙             | 水平                 | 0.13        | 0.04        |
| 内部楼板         | 向上                 | 0.10        | 0.10        |
| 内部顶棚         | 向下                 | 0.17        | 0.17        |
| 屋面             | 向上                 | 0.10        | 0.04        |
| 接地楼板         | 向下                 | 0.17        | 0.00*       |

*接地楼板采用单独的计算方法（ISO 13370）。

### 目标 U 值

| 构件          | 被动房        | 常见规范（气候区 5）          | 最低规范值   |
|--------------|---------------|-------------------------------|-------------|
| 外墙          | 0.10 - 0.15   | 0.25 - 0.30                   | 0.35 - 0.45 |
| 屋面          | 0.10 - 0.12   | 0.15 - 0.20                   | 0.25 - 0.30 |
| 楼板          | 0.10 - 0.15   | 0.20 - 0.25                   | 0.30 - 0.40 |
| 窗            | 0.80 - 1.00   | 1.40 - 1.80                   | 2.00 - 2.80 |

### 常见材料导热系数

| 材料                    | 导热系数（W/mK）    |
|------------------------|-------------------|
| 矿棉                    | 0.032 - 0.040     |
| EPS（膨胀聚苯板）       | 0.032 - 0.038     |
| XPS（挤塑聚苯板）       | 0.028 - 0.036     |
| PIR/PUR 板              | 0.020 - 0.025     |
| 酚醛泡沫                | 0.018 - 0.022     |
| 密实混凝土              | 1.13 - 1.93       |
| 中等密度混凝土砌块      | 0.51 - 0.70       |
| 普通砖                  | 0.62 - 0.77       |
| 软木材                  | 0.13 - 0.16       |
| 石膏板                  | 0.16 - 0.25       |
| 钢材                    | 50.0              |
| 玻璃                    | 1.05              |
| 不通风空气层            | 0.14 - 0.18*      |

*用于简化计算的等效导热系数。

## 3. 采光计算器

### BRE 简化公式

```
DF = (Aw x T x theta) / (A_total x (1 - R^2)) x 100
```

其中：
- DF = 平均采光系数（%）
- Aw = 窗的净玻璃面积（m2）
- T = 玻璃透光率（双层玻璃通常为 0.60 - 0.70）
- theta = 可见天空角系数（0 至 1，由天空角推导）
- A_total = 房间所有表面的总面积（楼地面 + 顶棚 + 墙体）
- R = 房间表面的面积加权平均反射比

### 天空角计算

可见天空角自窗中心向任何遮挡物顶部测量。对于无外部遮挡的窗：

```
theta_degrees = arctan((room_height - window_sill_height) / room_depth)
theta_factor = theta_degrees / 90
```

存在遮挡时，根据遮挡角降低 theta。

### 房间总表面积

```
A_total = 2 x (W x D) + 2 x (W x H) + 2 x (D x H)
```

其中 W = 宽度，D = 进深，H = 高度。

### 采光系数目标值

| 空间类型            | 最低 DF    | 建议 DF        |
|--------------------|-----------|---------------|
| 起居室              | 1.5%      | 2.0%          |
| 卧室                | 1.0%      | 1.5%          |
| 厨房                | 2.0%      | 2.5%          |
| 办公室              | 2.0%      | 3.0 - 5.0%   |
| 教室                | 2.0%      | 5.0%          |
| 医院病房            | 1.5%      | 2.5%          |
| 零售                | 2.0%      | 3.5%          |

### 出口宽度计算

```
总出口宽度（mm） = 使用人数 × 宽度系数
每个出口宽度 = 总宽度 / 出口数量
```

宽度系数：
- 楼梯：7.6 mm/人（0.3 英寸）
- 其他疏散构件：5.1 mm/人（0.2 英寸）
- 单樘门最小净宽：813 mm（32 英寸）
- 走道最小宽度：1118 mm（44 英寸）

## 5. 结构荷载计算器

### 竖向荷载计算

```
每层荷载 = 柱分担面积 ×（恒载 + 活载）
柱总荷载 = 每层荷载 × 楼层数
组合荷载 = 柱分担面积 ×（1.2 × DL + 1.6 × LL）× 楼层数
```

### 典型恒载

| 构造类型                       | 恒载（kN/m2）     |
|-------------------------------|-------------------|
| RC 楼板（200mm）               | 4.8               |
| RC 楼板（250mm）               | 6.0               |
| 钢承板 + 混凝土（130mm）        | 3.5               |
| 木楼板（搁栅）                 | 1.5               |
| 附加恒载（MEP、饰面）          | 1.0 - 1.5        |

### 典型活载（IBC 表 1607.1）

| 使用类型        | 活载（kN/m2）     | 活载（psf）     |
|----------------|-------------------|-----------------|
| 住宅            | 1.9               | 40              |
| 办公            | 2.4               | 50              |
| 零售（首层）    | 4.8               | 100             |
| 集会            | 4.8               | 100             |
| 仓储（轻型）    | 6.0               | 125             |
| 停车库          | 2.4               | 50              |
| 医院            | 3.8               | 80              |
| 学校            | 1.9               | 40              |

### 初步柱截面估算（RC）

```
所需面积 = 组合荷载 /（0.4 × fc'）
柱截面边长 = sqrt（所需面积）
```

其中 fc' 为混凝土抗压强度（通常为 30-40 MPa）。

## 6. 能耗计算器

### 度日法

```
Q_transmission = U_avg x A_envelope x HDD x 24 / 1000   (kWh/yr)
Q_ventilation = 0.33 x n x V x HDD x 24 / 1000          (kWh/yr)
Q_internal = q_int x A_floor x hours / 1000              (kWh/yr)

Heating Demand = Q_transmission + Q_ventilation - Q_internal
Cooling Demand = (U_avg x A_envelope x CDD x 24 / 1000)
              + (q_int x A_floor x cooling_hours / 1000)

EUI = (Heating + Cooling) / A_floor
```

其中：
- n = 通风换气次数（ACH）
- V = 建筑体积 = A_floor × 假定高度（3.0m）
- q_int = 室内得热（W/m2）
- hours = 供暖季小时数（HDD/avg_temp_diff × 24）

### 被动房目标

| 指标                         | 目标值                |
|-----------------------------|-----------------------|
| 供暖需求                     | <= 15 kWh/m2/年       |
| 制冷需求                     | <= 15 kWh/m2/年       |
| 一次能源（总量）             | <= 120 kWh/m2/年      |
| 气密性（n50）                | <= 0.6 ACH @ 50 Pa    |
| 过热发生频率                 | <= 温度 > 25C 小时数的 10% |
