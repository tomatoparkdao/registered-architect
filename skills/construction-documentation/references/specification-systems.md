# 技术规格体系参考

本参考综合介绍全球使用的技术规格分类体系：CSI MasterFormat（美国）、NBS（英国）、Uniclass 2015（英国）和 OmniClass。内容包括按分部整理的 MasterFormat 摘要、性能化技术规格编写指南以及可持续性规格实践。

## 1. CSI MasterFormat（美国）

## 2. NBS（国家建筑技术规格）——英国

### 2.1 概述

NBS 是英国使用最广泛的技术规格体系。NBS Chorus 是云端平台，支持结构化编写技术规格，并链接制造商产品数据和 BIM 对象。

### 2.2 主要特征

- **基于条款的体系：**每个章节包含带指导说明的标准条款
- **链接BIM对象：**技术规格可直接链接至BIM模型中的IFC对象
- **制造商产品数据：**直接链接至经过认证的产品数据
- **自动更新：**新版本发布时自动更新规范引用
- **NBS Source：**包含BIM对象和技术规格条款的产品库

### 2.3 NBS 章节结构

NBS 章节按工作成果组织：
- 前期/一般条件
- 地下结构
- 上部结构
- 室内饰面
- 机电服务
- 室外工程
- 家具与设备

## 5. Performance Specification Writing Guide

### 5.1 When to Use Performance Specifications

Performance specifications are appropriate when:
- Multiple products could satisfy the requirement
- Innovation from manufacturers is desired
- Long-term performance matters more than specific product selection
- The project delivery method transfers design responsibility to contractor
  (design-build)

### 5.2 Structure of a Performance Specification

**步骤 1：定义性能要求**
说明产品或系统必须达到的目标，而不是规定实现方式。

```
Example: "Exterior wall system shall achieve a thermal transmittance
(U-value) not exceeding 0.22 W/m2K when tested in accordance with
ISO 6946."
```

**步骤 2：引用测试标准**
引用规定性能测量方法的标准。

```
Example: "Acoustic performance: Minimum weighted sound reduction index
(Rw) of 55 dB when tested in accordance with ISO 10140."
```

**步骤 3：定义验收标准**
规定阈值以及证明符合要求的方式。

```
Example: "Submit independent laboratory test reports from an
ISO 17025 accredited laboratory demonstrating compliance with
specified performance values."
```

**步骤 4：规定质量保证**
明确安装人员资质、样板和现场测试要求。

```
Example: "Installer shall have minimum 5 years experience with
specified system type and shall provide references for 3 comparable
completed projects."
```

### 5.3 Performance Specification Examples

**幕墙系统：**
```
Performance Requirements:
- Air infiltration: Maximum 0.06 cfm/ft2 at 6.24 psf (ASTM E283)
- Water penetration: No uncontrolled water at 12 psf (ASTM E331)
- Structural: Withstand design wind load of 30 psf without permanent
  deformation (ASTM E330)
- Thermal: U-value not exceeding 0.40 Btu/hr-ft2-F (NFRC 100)
- Acoustic: Minimum STC 35 (ASTM E90)
- Deflection: L/175 maximum at design wind load
```

**地面系统：**
```
Performance Requirements:
- Slip resistance: Minimum dynamic coefficient of friction 0.42
  (ANSI A326.3)
- Abrasion resistance: PEI Class IV minimum (ISO 10545-7)
- Breaking strength: Minimum 2000 N (ISO 10545-4)
- Chemical resistance: Class A minimum (ISO 10545-13)
- Water absorption: Maximum 0.5% (ISO 10545-3)
```

### 5.4 性能规范中的常见问题

- 规定只有一个产品能够达到的性能值
  (effectively proprietary)
- 省略测试标准（没有测试方法，数值没有意义）
- 性能要求相互冲突
- 未规定现场验证方法
- 过度规定（要求现场条件达到实验室性能）

## 6. Sustainability Specifications

### 6.1 LEED Material Credit Documentation

Specifications play a critical role in documenting LEED compliance.
按学分划分的规格编写关键要求：

**MR 学分：建筑产品披露与优化**
- 环境产品声明（EPD）：规定采用第三方验证 EPD 的产品
  third-party verified EPDs (ISO 14025, EN 15804)
- 原材料来源：规定具有负责任开采认证的产品
  certifications (FSC for wood, recycled content documentation)
- 材料成分：规定具有健康产品声明
  (HPDs) or Cradle to Cradle certification

**EQ 学分：低排放材料**
- 涂料和涂层：按 SCAQMD Rule 1113 或 GreenSeal GS-11 控制 VOC 限值
- 胶粘剂和密封剂：按 SCAQMD Rule 1168 控制 VOC 限值
- 地面材料：取得 FloorScore 或 GreenLabel Plus 认证
- 木质复合材料：符合 CARB Phase 2（不得添加尿素甲醛）
- 吊顶和墙体系统：取得 GREENGUARD Gold 认证

**EA 学分：优化能源性能**
- 规定满足或超过能源规范的围护结构组件
- 在 Division 01 及相关分部中纳入调试要求
- 规定高效机电设备及其最低 COP/EER 值

### 6.2 Specification Clauses for Sustainability

Sample clause for recycled content:
```
Recycled Content: Provide products with minimum recycled content as follows:
- Structural steel: Minimum 90% recycled content
- Reinforcing steel: Minimum 95% recycled content
- Concrete: Minimum 30% supplementary cementitious material (SCM)
  replacing portland cement
- Gypsum board: Minimum 95% recycled gypsum core
- Acoustic ceiling tile: Minimum 70% recycled content
- Carpet: Minimum 40% recycled content by weight
Submit manufacturer's certified recycled content documentation.
```

Sample clause for regional materials:
```
Regional Materials: Where possible, provide products that have been
extracted, harvested, recovered, and manufactured within 500 miles
(800 km) of the project site. Submit documentation of product origin
including extraction/harvest location, manufacturing location, and
distance calculations.
```

### 6.3 Embodied Carbon Specifications

Emerging best practice includes embodied carbon requirements:

```
Embodied Carbon: Provide structural concrete with maximum Global
Warming Potential (GWP) of 250 kg CO2e per cubic meter for 30 MPa
mix. Submit mix design with GWP calculation per ISO 14067 or
equivalent Environmental Product Declaration.

Structural steel: Maximum GWP of 1.2 kg CO2e per kg of fabricated
steel. Electric Arc Furnace (EAF) steel preferred. Submit EPD or
mill-specific carbon intensity data.
```

## 7. Specification Coordination with Drawings

### 7.1 Cross-Referencing

- Drawing keynotes should reference specification section numbers
  (e.g., keynote "09 30 00" for ceramic tile)
- Specification sections should reference drawing sheet numbers for
  locations and details
- Avoid duplicating information between drawings and specifications;
  if conflict arises, specifications typically govern

### 7.2 Common Coordination Failures

- Specification names a product; drawing shows a different product
- Specification requires a performance level; drawing details prevent it
- Schedule lists a material; specification does not include that section
- Specification requires submittal; drawing notes "no submittal required"
- Division 01 requirements conflict with individual section requirements

### 7.3 Quality Control Process

1. Cross-reference check: Every material shown on drawings has a
   corresponding specification section
2. Product verification: Products named in specifications are available
   and currently manufactured
3. Standard verification: Referenced standards are current editions
4. Internal consistency: No conflicts between specification sections
5. Drawing coordination: Specification requirements physically achievable
   per drawn details
6. Code compliance: Specified products meet applicable code requirements
7. Budget verification: Specified products align with project budget
